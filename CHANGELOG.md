# Changelog

## 0.1alpha — first public alpha (planned)

This label starts the public release numbering. Development builds used private
0.8.0 and 0.9.0 labels; those files and their history are retained locally.
The version change does not remove or restart the existing implementation.

Included: the SKSE loader, native SDR color and sharpening pass, in-game menu,
settings persistence, input capture and automated tests.

Targets Skyrim Steam 1.7.104 with SKSE 2.3.1. Eleven automated tests pass.
Initial in-game feedback reports no issues. Wider compatibility remains to be checked.
