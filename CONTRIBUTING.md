# Contributing

Please describe the problem your change solves and how you tested it. Keep unrelated changes in separate pull requests.

## Code changes

Build the project and run CTest using the commands in [README.md](README.md). Use synthetic test data so contributors do not need game files or another mod's assets.

For rendering changes, explain the expected image change and any performance costs. Distinguish automated results from testing in Skyrim.

## Dependencies and attribution

Use code and assets whose licenses permit their inclusion. For a new dependency, record its upstream URL, version or commit, license and required notices.

Credits do not replace permission. Do not submit proprietary binaries, decompiled code, extracted signatures or third-party assets without a rights review.

Disclose AI-generated contributions and other code-generation tools in the pull request. Keep provenance records accurate.

## Repository contents

Do not commit local builds, private reference files, game installation paths or logs containing personal information. The mod package should contain only CGE and its required notices.

Project code is licensed under MIT. Third-party components keep their original licenses.
